# 地形を自由に変えるゲーム — プロトタイプ

TypeScript + Three.js。ボクセル地形を掘り、盛り、橋を架け、トンネルを貫いて
START から GOAL まで道路を通す。

このプロトタイプが検証しようとしているのは**トレードオフの構造が成立するか**であって、
地盤工学の再現度ではない。数字は「耐力」「荷重」「支保レベル」の3つだけで、すべて整数。
応力場も Mohr-Coulomb も浸透流も無い。

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm test         # シミュレーション層の単体テスト (vitest)
npm run build    # tsc --noEmit + vite build
npm run smoke    # Playwright で一連のプレイを再現し artifacts/ にスクリーンショット
```

## ルール

### 地質は3種類 + 地下水位1本

| 種類 | 色 | 耐力 | 必要支保レベル | 掘削 |
|---|---|---|---|---|
| 土 | 茶 | 2 | 1 | 普通 (¥22 / 0.3s) |
| 岩 | 灰 | 3 | 0 | 遅くて高い (¥75 / 1.2s) |
| 軟弱層 (砂・破砕帯) | 黄 | 0 | 2 | 楽 (¥12 / 0.2s) |

**地下水位 (y=10) より下は必要支保レベル +1。** 判断材料はこれで全部。

### 荷重 > 耐力 なら沈む

- 荷重 = `ceil(その支持点が受け持つ桁マス数 / 4)`
  受け持ち = 自セル + 左右の空間の半分ずつ
- 耐力 = 地盤の耐力 + 基礎補強 (大型基礎 +1 / 岩着杭 +3)
- 橋脚の直下4マス以内に**無支保の空洞**があると耐力は 0 になる。
  コンクリート覆工以上がされていれば低下は 1 で済む
- 岩着杭は直下6マス以内に岩があるところにしか打てない

> 設計の原案は「荷重 = 桁のマス数そのもの」だが、それだと支間20の吊橋(橋脚が21マス
> 受け持つ)と耐力3の岩が噛み合わない。除数を1つ挟んで同じ土俵に載せてある。
> マス目を数えれば予測できる性質は変わらない。

### 支間は表で決め打ち。超えたら建設できない

| 橋 | 支間 | 単価/マス |
|---|---|---|
| 木橋 | 3 | ¥60 |
| コンクリート橋 | 5 | ¥140 |
| 鋼橋 | 6 | ¥200 |
| トラス橋 | 10 | ¥320 |
| 吊橋 | 20 | ¥700 |

起点と終点を指定するとプラン状態になり、支間を満たす橋脚と、荷重を支えられる
**最も安い基礎**が自動で提案される。桁マスをクリックすれば橋脚を足し引きでき、
Shift+クリックで基礎を切り替えられる。支間超過や耐力不足のあいだはゴーストが赤くなり、
**確定そのものが拒否される。**

耐力不足は自分で作って確かめられる。トラス橋のプランで谷底の橋脚を Shift+クリックすると
岩着杭 (+3) → 直接基礎 (+0) に落ち、軟弱層の耐力 0 に対して荷重 3 になる。
橋脚の柱と現地のラベルが赤くなり、右下の表の該当行が赤くなり、確定ボタンが無効になる。
Shift+クリックを繰り返して岩着杭に戻せば、また建てられる。

建ててから落ちることは起きない。物理的な崩壊が起きるのは
**後から地面のほうが変わったとき**だけ。

### トンネルは支保レベル1つ

掘削は切土もトンネル掘進も同じ操作で、**土被りがあるかどうか**で支保の要否が決まる。
空に開いていれば支保は要らない。

| 支保 | レベル | 費用 | 施工 |
|---|---|---|---|
| 木枠 | 1 | ¥40 | 0.3s |
| コンクリート覆工 | 2 | ¥130 | 1.1s |
| 鋼製支保+排水 | 3 | ¥280 | 0.6s |

設置した支保が必要レベル未満なら劣化タイマーが走る。

### 予兆 → 猶予 → 崩壊。即死は作らない

猶予は**不足レベルによらず常に25秒**。深刻さは「直す費用」で表現し、「残り時間」では
表現しない。残り60%を切ると予兆フェーズに入り、天端から砂が落ち、赤が強く脈打ち、
画面端が赤くなる。

**猶予中に直せば必ず元に戻る。** 支保を上げても、埋め戻しても、基礎を補強してもよい。

時間切れになると、トンネルは元の地質で埋め戻り、隣接する未対策セルの猶予が半分に削られる
(連鎖)。土被りが3以下なら地表まで陥没する。橋脚は受け持っていた桁ごと落ちる。

### 可視化はトグル1つ

**G キー**(またはボタン1つ)で地質ビュー。押すと

1. スライダーの位置で地面が手前から切り開かれ (クリップ面のワイプ)
2. 切り口に地層の断面図が現れ
3. 調査済みの列だけがはっきりした地質色になり、未調査の列は薄い影のまま
4. ボーリングコアが立つ

地図は初期状態で地質不明。**ボーリング1本 (¥260) で、その位置の地層が縦一列だけ見える。**
自然にできた崖や谷壁は露頭なので、そこだけは調査せずに色が見える。
世界の縁は人工的な切り口なので、地質をタダでは見せない。

危険箇所のオーバーレイは赤い脈動1種類だけ。

### ミッション

START から GOAL まで、**段差1で歩ける経路**を通せば開通。ただし
**道路として認める経路長は74マスまで。**

この上限が無いと「遠回りはタダ」になり、トンネルも切土も選ぶ理由が消える。
遠回りにも値段をつけるための、たった1つの数字。

## 生まれるトレードオフ

初期地形 (シード固定) は「開始台地 → 谷 → 尾根 → 到達台地」。
谷底は河川堆積物で軟弱、尾根には斜めに走る破砕帯が仕込んである。

**谷の渡り方** (x=12→29, 17マス)

| | 費用 | 内訳 |
|---|---|---|
| 木橋 | ¥3,330 | 橋脚4本。1本あたりの荷重は小さいので大型基礎で足りる |
| トラス橋 | ¥6,865 | 橋脚1本。荷重が集中するので岩着杭が要る |
| 吊橋 | ¥12,600 | 橋脚なしで一気に渡す。軟弱な谷底に一切触らない |

**尾根の抜け方** (橋を架けただけでは経路82マスで上限超過)

| | 経路 | 支保が要るセル |
|---|---|---|
| 破砕帯を突っ切る (z=16) | 56 マス | 6 |
| 横にずらして岩盤を狙う (z=10) | 68 マス | 0 |

支保コストを払って最短で抜けるか、破砕帯を避けて遠回りするか。
そしてそれを判断するには、**先に調査に金を払うか、勘で掘って事故るか**を決める必要がある。

橋脚の下にトンネルを通すと耐力が落ちる。覆工しておけば低下は1で済むが、
トラス橋の荷重3には届かない ——「そこは通せない」と地面のほうが教えてくる。

## 遊び方

**起動すると遊び方の画面が開いた状態で始まる** (時間は止まっている)。
以降はいつでも `H` で開ける。画面下中央には、状況に応じた「次にやること」が常に1行出る。
視点は `W A S D` (または矢印キー) で上下左右に動かせる。

1. **地形を見る** — 崖や谷壁は露頭なので、掘らなくても地質の色が見える。黄色が軟弱層
2. **ボーリングを打つ** (`1`) — 1本 ¥260。その位置の地層が縦一列だけ見える。`G` の地質ビューで確認する
3. **谷に橋を架ける** — 左のパレットで橋種を選び、起点 → 終点の順にクリック。支間と荷重を満たす橋脚・基礎が自動で提案される。桁マスをクリックで橋脚を足し引き、Shift+クリックで基礎を切替。右下の表で 荷重 ≤ 耐力 を確認して `Enter`
4. **尾根を抜ける** — 掘削 (`2`) で坑道を掘る。土被りがあるセルは支保 (`4`〜`6`) が要る。切土なら要らない
5. **段差を均す** — 段差2以上は歩けないので、盛土 (`3`) と掘削でつなぐ

崩壊は必ず予告される。左下に残り秒数が出て、猶予は25秒。
**猶予のうちに直せば必ず元に戻る**(支保を上げる / 埋め戻す / 基礎を補強する)。
警告の行をクリックすると、その場所にカメラが飛ぶ。

## 操作

| 入力 | 動作 |
|---|---|
| 左クリック | 選択中の道具を適用 |
| `W A S D` / 矢印 | 視点を上下左右に動かす (`Shift` で速く) |
| 左ドラッグ / 右ドラッグ / ホイール | 回転 / 平行移動 / ズーム |
| `1`–`6` | 調査 / 掘削 / 盛土 / 木枠 / 覆工 / 鋼製支保 |
| `G` | 地質ビュー |
| `H` | 遊び方 |
| `Enter` / `Esc` | プランの確定 / 取消 |
| `Space` | 一時停止 (猶予の観察用) |

橋 (5種)・基礎補強・撤去は左のパレットのボタンから選ぶ。
`W A S D` を視点移動に使うので、道具のショートカットは数字キーだけにしてある。

橋の建設は起点クリック → 終点クリック → プランを調整 → `Enter`。

## 構成

```
src/
  core/     config.ts (全チューニング定数) / types.ts / rng.ts
  sim/      描画から完全に切り離したゲーム本体。テストはここを直接叩く
            VoxelWorld · worldgen · tunnel · bridge · hazard · survey · economy · mission · Game
  render/   Scene · ChunkMesher · TerrainView · StructureView · Effects · Picker · Ghost
  ui/       Hud · tools · styles.css
  debug/    api.ts — window.__game (スモークテストの操作口)
tests/      vitest。sim/ の単体テストと統合テスト
scripts/    smoke.mts — Playwright で一連のプレイを再現しスクリーンショットを残す
```

**バランス調整は `src/core/config.ts` の数字を触るだけで完結する。**

## 検証

`npm test` (69件) がシミュレーション層を、`npm run smoke` が実際のブラウザ上での
一連のプレイを検証する。スモークが確認しているのは主に:

- 支間を超えた橋は建設前に拒否され、支払いも発生しない
- 無支保で軟弱層を掘ると予兆を経て崩落し、元の地質で埋め戻る
- 支保を入れれば崩れない。木枠(1)では軟弱層(2)に足りない
- 橋を架けただけでは経路が長すぎて開通せず、尾根を貫くと開通する
- 橋脚の下を掘ると沈下が始まり、猶予中に埋め戻せば元に戻る

スクリーンショットは `artifacts/` に出力される。

## 割り切っていること

プロトタイプなので、以下は意図的に作っていない。

- 音 (WebAudio) — 視覚演出のみ
- 地形の保存・読み込み、複数ステージ、リプレイ
- 作業班は1つだけ (作業は順番に1つずつ処理される)
- トンネルの断面は1セル。複線・分岐は掘れるが断面形状は持たない
- 交通量や維持管理。開通した後に道路が使われることはない
