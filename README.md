# 地形を自由に変えるゲーム — プロトタイプ

TypeScript + Three.js。ボクセル地形を掘り、盛り、橋を架け、トンネルを貫いて
START から GOAL まで道路を通す。

このプロトタイプが検証しようとしているのは**トレードオフの構造が成立するか**であって、
地盤工学の再現度ではない。数字は「耐力」「荷重」「支保レベル」の3つだけで、すべて整数。
応力場も Mohr-Coulomb も浸透流も無い。

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm test         # シミュレーション層の単体テスト (vitest)
npm run build    # tsc --noEmit + vite build
npm run smoke    # Playwright で一連のプレイを再現し artifacts/ にスクリーンショット
npx tsx scripts/probe.mts   # バランスの計測 (下の実測表はここの出力)
```

## ルール

### 地質は3種類 + 地下水位1本

| 種類 | 色 | 耐力 | 必要支保レベル | 掘削 |
|---|---|---|---|---|
| 土 | 茶 | 2 | 1 | 普通 (¥22 / 0.3s) |
| 岩 | 灰 | 3 | 0 | 遅くて高い (¥75 / 1.2s) |
| 軟弱層 (砂・破砕帯) | 黄 | 0 | 2 | 楽 (¥12 / 0.2s) |

**地下水位 (y=10) より下は必要支保レベル +1。** 判断材料はこれで全部。

### 1セルは 横8m × 縦2m

勾配を現実の % で語るための宣言で、格子そのものは 64×32×32 のまま。

縦を細かく刻む (`SY` を増やす) 方法もあるが、それだと「トンネルの断面は縦1セル」という
前提が壊れ、支保・掘削費・掘削時間・`VOID_CHECK_DEPTH`・`PILE_REACH`・`SINKHOLE_COVER`・
水位を全部引き直すことになる。寸法を宣言し直すだけなら、シミュレーションは1行も変わらずに
勾配だけが現実の土俵に乗る。

> 描画は縦を4倍に誇張している (地形図の縦断図と同じ約束事)。`V_RENDER` を下げれば
> 実寸比に近づくが、起伏の迫力は落ちる。

### 荷重 > 耐力 なら沈む

- 荷重 = `ceil(その支持点が受け持つ桁マス数 / 4)`
  受け持ち = 自セル + 左右の空間の半分ずつ
- 耐力 = 地盤の耐力 + 基礎補強 (大型基礎 +1 / 岩着杭 +3)
- 橋脚の直下4マス以内に**無支保の空洞**があると耐力は 0 になる。
  コンクリート覆工以上がされていれば低下は 1 で済む
- 岩着杭は直下6マス以内に岩があるところにしか打てない

> 設計の原案は「荷重 = 桁のマス数そのもの」だが、それだと支間20の吊橋(橋脚が21マス
> 受け持つ)と耐力3の岩が噛み合わない。除数を1つ挟んで同じ土俵に載せてある。
> マス目を数えれば予測できる性質は変わらない。

### 支間は表で決め打ち。超えたら建設できない

| 橋 | 支間 | 単価/マス |
|---|---|---|
| 木橋 | 3 | ¥60 |
| コンクリート橋 | 5 | ¥140 |
| 鋼橋 | 6 | ¥200 |
| トラス橋 | 10 | ¥320 |
| 吊橋 | 20 | ¥700 |

起点と終点を指定するとプラン状態になり、**支間を満たす橋脚だけ**が自動で配置される。
**基礎は勝手に決めない。** 全部まず直接基礎 (+0) から始まる。

谷底は軟弱層 (耐力0) なので、トラス橋を架けようとすると橋脚の柱と現地のラベルが赤くなり、
右下の表に `荷重 3 > 耐力 0` が出て確定ボタンが無効になる。ここでプレイヤーが選ぶ:

- **基礎を上げる** — Shift+クリックで 直接基礎 → 大型基礎 (+1) → 岩着杭 (+3)。
  右下の「基礎を補う (+¥520)」を押せば、足りない分をまとめて最も安い組み合わせに上げる
- **橋脚を増やす** — 桁マスをクリック。1本あたりの荷重が下がる (ただし耐力0の地盤は大型基礎が要る)
- **橋脚の要らない橋にする** — 吊橋なら支間20なので谷底に一切触らずに済む (そのぶん高い)

耐力不足のまま確定しようとしても建たず、支払いも発生しない。

> 以前は最も安い基礎を自動で提案していたが、それだと軟弱層が「黙って値段が上がるだけ」に
> なり、判断がプレイヤーの手から消えていた。いまは一度必ず赤で見せてから、値段つきで選ばせる。

建ててから落ちることは起きない。物理的な崩壊が起きるのは
**後から地面のほうが変わったとき**だけ。

### トンネルは支保レベル1つ

掘削は切土もトンネル掘進も同じ操作で、**土被りがあるかどうか**で支保の要否が決まる。
空に開いていれば支保は要らない。

| 支保 | レベル | 費用 | 施工 |
|---|---|---|---|
| 木枠 | 1 | ¥40 | 0.3s |
| コンクリート覆工 | 2 | ¥130 | 1.1s |
| 鋼製支保+排水 | 3 | ¥280 | 0.6s |

設置した支保が必要レベル未満なら劣化タイマーが走る。

### 予兆 → 猶予 → 崩壊。即死は作らない

猶予は**不足レベルによらず常に25秒**。深刻さは「直す費用」で表現し、「残り時間」では
表現しない。残り60%を切ると予兆フェーズに入り、天端から砂が落ち、赤が強く脈打ち、
画面端が赤くなる。

**猶予中に直せば必ず元に戻る。** 支保を上げても、埋め戻しても、基礎を補強してもよい。

時間切れになると、トンネルは元の地質で埋め戻り、隣接する未対策セルの猶予が半分に削られる
(連鎖)。土被りが3以下なら地表まで陥没する。橋脚は受け持っていた桁ごと落ちる。

### 地形はボクセルに見せない

シミュレーションはボクセル格子のままだが、描画は **Surface Nets** で滑らかにしてある。

1. セル中心を格子点として、8セルの塊ごとに頂点を1つ置く
   (角で占有率を平均する作り方だと、1セル幅の坑道が閉じて消えてしまう)
2. **手つかずの地表は `worldgen` の連続高さ (float) の曲面へ最短距離で吸着させる。**
   ここが一番効く。真上下に動かすだけだと急斜面が段々畑のまま残るので、
   曲面への最短距離で寄せている。平らなところでは上下移動に、急斜面では自動的に
   横移動になる
3. 掘った跡・盛った跡は拘束付きラプラシアン平滑化。各頂点は自分のセルから
   半マス以上は動かない (マス目の予測可能性を守るため)
4. 周囲の詰まり具合から陰 (AO) を頂点カラーに焼く

滑らかにするとマス目が数えられなくなるので、**薄い等高線**を重ねてある
(5本ごとに計曲線)。地形図らしく見えるうえに、高さが読める。

平滑化は見た目だけで、耐力・荷重・支保・崩壊の判定は1セルも動かない。

### 可視化はトグル1つ

**G キー**(またはボタン1つ)で地質ビュー。押すと

1. スライダーの位置で地面が手前から切り開かれ (クリップ面のワイプ)
2. 切り口に地層の断面図が現れ
3. 調査済みの列だけがはっきりした地質色になり、未調査の列は薄い影のまま
4. ボーリングコアが立つ

地図は初期状態で地質不明。**ボーリング1本 (¥260) で、その位置の地層が縦一列だけ見える。**
自然にできた崖や谷壁は露頭なので、そこだけは調査せずに色が見える。
世界の縁は人工的な切り口なので、地質をタダでは見せない。

危険箇所のオーバーレイは赤い脈動1種類だけ。

### 勾配は 8.3% まで — 1マス上下するのに3マスの走りが要る

これが数字その3。1セルが横8m×縦2mなので、段差1が連続すると 25% 勾配になり、
道路としてはありえない。上下した直後の2マスは平坦でなければならない、という
たった1つの制約を経路探索に足してある。上りも下りも同じ。

**この1つの数字が、橋とトンネルを「近道」から「そこを通る唯一の手段」に変える。**
勾配ルールが無かったときは、谷を歩いて降りて登り返せてしまうので、橋は
「あったほうが速い」程度のものだった。いまは初期地形では谷に**到達すらできない**。

横に振れる余地があれば九十九折りで登れる。現実の峠道と同じで、遠回りという値段を払う。

### 道路敷設 (整地)

勾配上限を入れると、台地の細かい起伏もそのままでは道路にならない。1マスずつ手で
均させるのは作業であって判断ではないので、起点→終点を指定すればまとめて発注できる。

帯の縦断形を勾配条件を満たすように刻み、路面より上を切土、下を盛土する。
値段は**既存の掘削/盛土の単価そのまま**なので、新しく覚える数字は無い。
発注する前に切土/盛土の量と総額が出る (橋と同じ「建てる前に分かる」の作法)。

### ミッション

START から GOAL まで、**勾配 8.3% 以内で通せる経路**を引けば開通。ただし
**道路として認める経路長は74マスまで。**

この上限が無いと「遠回りはタダ」になり、トンネルも切土も選ぶ理由が消える。
遠回りにも値段をつけるための、たった1つの数字。

## 生まれるトレードオフ

初期地形 (シード固定) は「開始台地 → 谷 → 尾根 → 到達台地」。
谷底は河川堆積物で軟弱、尾根には斜めに走る破砕帯が仕込んである。

**まず、素の地形では谷に到達できない。** 勾配 8.3% では谷壁 (1マスで3〜5マス落ちる) を
降りられないので、`✕ 未通` のまま工事中の道路が谷の手前で途切れる。

**谷の渡り方** (x=12→29, 17マス。基礎込みの実測)

| | 費用 | 橋脚 | 内訳 |
|---|---|---|---|
| 木橋 (支間3) | ¥3,330 | 4本 | 1本あたりの荷重が小さいので大型基礎で足りる |
| コンクリート橋 (支間5) | ¥4,730 | 2本 | 谷底が軟弱なので岩着杭が2本要る |
| 鋼橋 (支間6) | ¥5,810 | 2本 | 同上。単価が上がるぶん高い |
| トラス橋 (支間10) | ¥6,865 | 1本 | 荷重が集中するので岩着杭 (+¥520) |
| 吊橋 (支間20) | ¥12,600 | 0本 | 軟弱な谷底に一切触らない |

**尾根の抜け方** (台地の高さ y=19 を保ったまま通す)

| | 経路 | 支保が要るセル | 総額 |
|---|---|---|---|
| 破砕帯を突っ切る (z=16) | 56 マス | 6 | ¥8,136 |
| 横にずらして岩盤を狙う (z=10) | 68 マス | 0 | ¥7,712 |

安いのは遠回りのほう。ただし上限74マスに対して68マスなので、**もう寄り道の余地が無い**。
高くつくのは最短のほうで、そのぶん経路に18マスの余裕が残る。
そしてどちらが安いかは、**先に調査に金を払わないと分からない**。

初期予算 ¥15,000 に対し、最短の解き方で総額 ¥8,136。吊橋で渡ると ¥13,871 で、
ほぼ使い切る。

支保コストを払って最短で抜けるか、破砕帯を避けて遠回りするか。
そしてそれを判断するには、**先に調査に金を払うか、勘で掘って事故るか**を決める必要がある。

橋脚の下にトンネルを通すと耐力が落ちる。覆工しておけば低下は1で済むが、
トラス橋の荷重3には届かない ——「そこは通せない」と地面のほうが教えてくる。

## 遊び方

**起動すると遊び方の画面が開いた状態で始まる** (時間は止まっている)。
以降はいつでも `H` で開ける。画面下中央には、状況に応じた「次にやること」が常に1行出る。
視点は `W A S D` (または矢印キー) で上下左右に動かせる。

1. **地形を見る** — 崖や谷壁は露頭なので、掘らなくても地質の色が見える。黄色が軟弱層
2. **ボーリングを打つ** (`1`) — 1本 ¥260。その位置の地層が縦一列だけ見える。`G` の地質ビューで確認する
3. **谷に橋を架ける** — 左のパレットで橋種を選び、起点 → 終点の順にクリック。支間を満たす橋脚は自動で入るが、**基礎は入らない**。谷底は耐力0なので赤くなるので、基礎を上げる (Shift+クリック / 「基礎を補う」ボタン) か、橋脚を増やすか、吊橋にするかを選ぶ。右下の表で 荷重 ≤ 耐力 になったら `Enter`
4. **尾根を抜ける** — 掘削 (`2`) で坑道を掘る。土被りがあるセルは支保 (`5`〜`7`) が要る。切土なら要らない
5. **道路をならす** — 道路敷設 (`4`) で起点→終点を指定すると、勾配条件を満たす縦断形に切り盛りしてくれる。1マスずつやりたいときは掘削 (`2`) と盛土 (`3`)

道路は常に描かれる。開通していれば舗装として、まだ届いていなければ**工事中の色で
途切れたところまで**。「いまどこで止まっているのか」が画面を見れば分かる。

崩壊は必ず予告される。左下に残り秒数が出て、猶予は25秒。
**猶予のうちに直せば必ず元に戻る**(支保を上げる / 埋め戻す / 基礎を補強する)。
警告の行をクリックすると、その場所にカメラが飛ぶ。

## 操作

| 入力 | 動作 |
|---|---|
| 左クリック | 選択中の道具を適用 |
| `W A S D` / 矢印 | 視点を上下左右に動かす (`Shift` で速く) |
| 左ドラッグ / 右ドラッグ / ホイール | 回転 / 平行移動 / ズーム |
| `1`–`7` | 調査 / 掘削 / 盛土 / 道路敷設 / 木枠 / 覆工 / 鋼製支保 |
| `G` | 地質ビュー |
| `H` | 遊び方 |
| `Enter` / `Esc` | プランの確定 / 取消 |
| `Space` | 一時停止 (猶予の観察用) |

橋 (5種)・基礎補強・撤去は左のパレットのボタンから選ぶ。
`W A S D` を視点移動に使うので、道具のショートカットは数字キーだけにしてある。

橋の建設は起点クリック → 終点クリック → プランを調整 → `Enter`。
道路敷設も起点クリック → 終点クリックで、途中は切土/盛土の量と値段がプレビューされる。

## 構成

```
src/
  core/     config.ts (全チューニング定数) / types.ts / rng.ts
  sim/      描画から完全に切り離したゲーム本体。テストはここを直接叩く
            VoxelWorld · worldgen · tunnel · bridge · hazard · survey · economy
            mission (勾配つき経路探索) · alignment (道路の線形) · Game
  render/   Scene · ChunkMesher (Surface Nets) · TerrainView · RoadView
            StructureView · Effects · Picker (ボクセルレイマーチ) · Ghost
  ui/       Hud · tools · styles.css
  debug/    api.ts — window.__game (スモークテストの操作口)
tests/      vitest。sim/ の単体テストと統合テスト
scripts/    smoke.mts — Playwright で一連のプレイを再現しスクリーンショットを残す
            probe.mts — 経路長・費用・土量の計測 (README の実測表の出どころ)
```

**バランス調整は `src/core/config.ts` の数字を触るだけで完結する。**

## 検証

`npm test` (104件) がシミュレーション層を、`npm run smoke` が実際のブラウザ上での
一連のプレイを検証する。スモークが確認しているのは主に:

- 勾配上限があるので、素の地形では谷を渡れず、工事中の道路が手前で途切れる
- 支間を超えた橋は建設前に拒否され、支払いも発生しない
- 無支保で軟弱層を掘ると予兆を経て崩落し、元の地質で埋め戻る
- 支保を入れれば崩れない。木枠(1)では軟弱層(2)に足りない
- 橋を架けただけでは経路が長すぎて開通せず、尾根を貫くと開通する
- 橋脚の下を掘ると沈下が始まり、猶予中に埋め戻せば元に戻る
- 急すぎる道路敷設は発注前に断られ、通った道路は勾配上限を守っている

単体テストで特に押さえているのは、平滑化がシミュレーションを壊していないこと:

- 同じ入力からは同じメッシュができる (決定的)
- **1セル幅の坑道が平滑化で塞がらない** (回帰の要)
- 手つかずの地表が連続曲面に乗っている
- 線形は経路の帯から出ず、すりつけたあとも勾配上限を守る

スクリーンショットは `artifacts/` に出力される。

## 割り切っていること

プロトタイプなので、以下は意図的に作っていない。

- 音 (WebAudio) — 視覚演出のみ
- 地形の保存・読み込み、複数ステージ、リプレイ
- 作業班は1つだけ (作業は順番に1つずつ処理される)
- トンネルの断面は1セル。複線・分岐は掘れるが断面形状は持たない
- 道路は1本だけ。分岐も交差点もない
- 車線・標識・ガードレールといった付属物
- 交通量や維持管理。開通した後に道路が使われることはない
